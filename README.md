# Bem-vindo ao Zammad

Você está malabarizando inúmeras solicitações de clientes em vários canais?
Está difícil manter sua equipe de suporte em sintonia?
Ou está passando mais tempo gerenciando seu helpdesk do que entregando um suporte excepcional aos seus clientes?

O Zammad é o seu canivete suíço — uma plataforma de helpdesk e suporte ao cliente baseada na web e de código aberto, repleta de recursos para simplificar a comunicação com o cliente em canais como e-mail, chat, telefone e redes sociais.

## O Software

O software Zammad é e continuará sendo código aberto. Ele é licenciado sob a GNU AGPLv3.
O código-fonte está [disponível no GitHub](https://github.com/zammad/zammad) e pertence à [Zammad Foundation](https://zammad-foundation.org/), que é independente de provedores comerciais como a Zammad GmbH.

## A Empresa - Zammad GmbH

O desenvolvimento do Zammad é realizado pela [incrível equipe de pessoas](https://zammad.com/en/company) da [Zammad GmbH](https://zammad.com/) em colaboração com a comunidade.
Nós amamos criar software de código aberto para você. Se você deseja garantir que o software Zammad tenha um futuro brilhante e sustentável, considere se tornar um cliente Zammad!

> Cansado de tarefas complexas de instalação, configuração, backup e atualização? Deixe que cuidamos disso para você! 🚀
>
> A maneira mais fácil e frequentemente mais acessível de operar o Zammad é [nosso serviço em nuvem](https://zammad.com/en/pricing).
> Faça um teste com uma [instância de teste gratuita](https://zammad.com/en/getting-started)!
